Privacy Policy

Last updated: October 22, 2026

Who we are

"Kept Quiet Uploader" is a private tool operated by the owner of the Kept Quiet YouTube channel. It is used only to manage that one channel and is not available to the public.

What data the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos, set thumbnails and captions, read basic channel information and update channel settings of the owner's own channel. It does not access any other user's data.

Use of YouTube API Services

Kept Quiet Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. YouTube data is handled under the Google Privacy Policy.

What we store and for how long

The only stored item is the OAuth refresh token for the owner's channel, kept as an encrypted environment secret in the owner's private build environment so that uploads can run. Data returned by the API (for example the ID of an uploaded video) is used only during that run and is not stored. We use no cookies, no analytics and no third-party sharing. No personal data of viewers or other YouTube users is ever collected, stored, sold or shared.

How to revoke access and delete data

Access can be revoked at any time from the Google security settings page. When access is revoked, or on request to the email below, the stored refresh token is deleted within 7 days.
