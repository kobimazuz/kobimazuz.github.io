Privacy Policy

Last updated: October 22, 2026

Who we are

"Kept Quiet Uploader" is a private tool operated by the owner of the Kept Quiet YouTube channel. It is used only to manage that one channel and is not available to the public.

What data the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos, set thumbnails and captions, read basic channel information and update channel settings of the owner's own channel. It does not access any other user's data.

How data is stored

The OAuth credentials are stored as encrypted environment secrets in the owner's private build environment. No personal data of viewers or other users is collected, stored, sold or shared.

YouTube and Google

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and the Google Privacy Policy applies. Access can be revoked at any time at Google security settings.
